# PMAOS Release Status

This page records the current public status of each PMAOS component and platform, and defines the status vocabulary used across this repository. See the [README](../README.md) for an overview of PMAOS.

## Current Status

| Component / Platform | Public Status |
|---|---|
| PMAOS Mobile on UNISOC T127 / 64MB | Production / initial commercial deployment |
| PMAOS AI Runtime | POC / continuing iteration |
| ASR3605 platform integration | POC completed |
| General-purpose LLM locally on documented 64MB configuration | Not claimed |

## Status Definitions

### Production

The component has shipped in an actual mass-production configuration.

### POC

The technical path has been validated. This must not be interpreted as a production deployment.

### Planned

A future goal. Does not represent current capability.

All pages in this repository follow these status definitions.
